# Marvin's Blog: A Hitchhiker's Guide to the Galaxy-Themed Django Project

A **Django-based blog** project created as part of the [Udemy course: *Python Django - The Practical Guide*](https://www.udemy.com/course/python-django-the-practical-guide/learn/lecture/26399412#overview).
This project demonstrates the practical implementation of Django concepts, including models, views, templates, forms, and user authentication, while themed around *The Hitchhiker's Guide to the Galaxy* and Marvin, the Paranoid Android.

---

## Features

- **Post Management**: Create, read, update, and delete blog posts.
- **Comment System**: Users can leave comments on posts.
- **Tagging**: Posts can be categorized with tags.
- **User Authentication**: Sign up, log in, and manage user profiles.
- **Responsive Design**: Styled with a custom *Hitchhiker's Guide to the Galaxy* theme (dark backgrounds, gold accents, and purple highlights).
- **Static Files**: Proper handling of CSS and images.

---

## Techniques Used

- **Backend**: Python, Django
- **Frontend**: HTML, CSS
- **Database**: SQLite (default for Django)
- **Styling**: Custom CSS with a sci-fi theme
